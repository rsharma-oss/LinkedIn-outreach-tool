One LinkedIn data request triggers two separate zip files — both uploaded exactly the same way (drag & drop or Chrome/Edge folder picker). They just arrive at different times:

Basic export — arrives within 24 hours. Contains your Connections and Messages. This is everything the ICP Finder and Playbook need — start here as soon as it lands.

These are desktop tools by design — dense dashboards, large contact tables, and 18 charts that need real screen width to be readable.

There's also a hard technical reason: loading your export uses the browser's folder/file picker (the File System Access API), which mobile browsers don't support. You can read this page and explore the demos on a phone, but to load your own data use a laptop or desktop.

It still works in Safari and Firefox — Chrome and Edge just give the smoothest path, for two reasons:

  1. One-click folder upload. The "Select Export Folder" button uses the File System Access API, which only Chrome and Edge support. In Safari/Firefox you pick the CSV files manually instead — a couple extra clicks, same result.
  2. Storage headroom. Safari caps per-tab storage (~5MB) lower than Chrome (~10MB), so very large networks (10k+ connections) can hit the limit. Either way, nothing ever leaves your browser.
